## Overview

A set of focused technical projects on the fundamentals that make machine learning reliable: choosing models, tuning them and measuring them properly.

## Techniques

- **Logistic regression** for classification.
- **GridSearchCV** for systematic hyperparameter tuning.
- **Model evaluation and testing** on held-out data.
- **K-Means clustering** for unsupervised grouping.
- **PCA** for dimensionality reduction.

## Why it matters

The same evaluation discipline carries into client work: every model is judged on data it hasn't seen, with metrics chosen for the real decision.

## Overview

This project develops a passenger detection model for in-vehicle camera systems, using the YOLOX-S object detector. The intended target is a vehicle's edge ECU, which shapes model choice from the start. The work is **in progress**.

## Problem statement

Detecting passengers reliably from in-vehicle camera images, within the compute limits of an embedded automotive processor.

## Dataset and annotation

Images are collected and annotated with bounding boxes for passengers, then organised into training, validation and test splits.

## Training methodology

YOLOX-S, a compact member of the YOLOX family, is trained on the annotated dataset. Its small size suits edge hardware.

## Model evaluation

The model will be evaluated on held-out data. Results will be published here only once they have been measured.

## Edge deployment considerations

Model size, inference latency and the target ECU's hardware constraints guide the choice of architecture and any optimisation steps.
